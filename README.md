# 📖 About

Understanding code is one of the biggest challenges for beginners.

Most platforms only show code.

**CodeSamjho lets you WATCH your code execute.**

Instead of reading static code, users can visualize:

- Variables changing in real-time
- Loop execution
- Function calls
- Memory allocation
- Arrays
- Trees
- Graphs
- Recursion
- Console output
- AI-powered explanations

The goal is to make programming **visual, interactive, and intuitive.**
