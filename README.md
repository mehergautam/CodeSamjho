# ⚡ CodeSutra
### Don't just read code. See how it works.

CodeSutra is an interactive code understanding platform that transforms source code into a visual execution experience.

Instead of mentally tracing code line by line, CodeSutra helps you **see what is happening inside your program** — variables changing, conditions evaluating, loops executing, functions being called, recursion expanding, arrays mutating, and values returning through the call stack.

---

## 🚀 Why CodeSutra?

Understanding code is often harder than writing it.

When reading a program, developers—especially beginners—have to mentally track:

- Which line executes next?
- What is the current value of each variable?
- Why did this condition become `true`?
- How many times has this loop executed?
- What happens when a function calls another function?
- How does recursion actually work?
- What happens inside the call stack?
- How does an array change during an algorithm?

**CodeSutra turns that mental process into a visual experience.**
